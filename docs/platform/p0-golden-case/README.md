本目录是 `Consultation_Sandbox_Architecture_v0.1.md` §9 P0 阶段的第一份可执行规格：一个完整 CaseTruth 实例 + 22 条 rubric。目的不是病例本身，而是**用一份写满的实例把抽象 schema 的所有含糊处逼成决策**。

## 一、写实例逼出的四个决策（写回架构文档的增量）

### 决策 1：谓词采用「auto 为主、judge 兜底」的混合，且 auto 占多数

写完 22 条后比例自然落在 16 auto : 6 judge。规律：**凡是能归约为「轨迹中存在某类型化事件」的条款都走 auto**（问诊覆盖、查体、开单、诊断编码、费用区间），judge 只留给三件事：**语义充分性**（教育是否「患者能懂」）、**复合条件**（R17 = 教育∧血压管理）、**未结构化输出的质量**（R19 通俗解释）。推论：auto 比例取决于动作类型化的颗粒度——CPOE 菜单做得越细，judge 越少、评分越便宜越稳。

### 决策 2：`second_ask_concede` 成为 schema 一等公民

真实问诊里患者第一次问不会说真话（依从性、饮酒量）。实例证明这必须是**应答表字段**而非 prompt 技巧：`medication_adherence` 与 `smoking_alcohol` 两个主题带 `second_ask_concede`，reveal_policy 里有对应 override，rubric 里对应 R04/R08 两条「追问后才命中」的谓词（`ASKED_AFTER_FOLLOWUP`）。考的不是「问了没有」而是「追问了没有」——单次提问拿到的是假依从。

### 决策 3：条款依赖（depends_on）显式化，且「依赖未打通」本身是诊断信号

R14（诊断高血压）依赖 R09（测了血压）——没测就不可能诊断。但依赖失败**不判 NOT_APPLICABLE 而仍判定并标注**，因为报告里「过程分低 + 结果分低 + 依赖未打通」的组合恰好指出学员的具体缺陷路径（漏查体→漏诊断），这正是教学反馈要的信息。

### 决策 4：目录边界与无指征检查都进了检查结果表

`fundus_screening`（本院未开展→考转诊）和 `ogtt`（已确诊无指征→考克制）证明：**考题可以直接长在结果表里**，不需要额外机制。费用分条款必须与鉴别需求联判（TSH ¥180 用于消瘦鉴别不扣分）。

## 二、主题路由表（从症状应答表自动派生）

路由器的枚举空间 = `symptom_response_table.topics` 的 14 个 key + 通用槽。路由规则：

1. **一问一主题优先**：多数问句只命中一个 topic；多主题问句（「胃口怎么样，体重有没有变」）允许返回 N 个，窗口合并装配。
2. **passive 主题需要语义直接命中**：`foot_numbness` 的命中定义是问句涉及「麻木/感觉异常/手脚感觉」，问「脚有没有破」不算——`denies` 里有「没破过」但那是 foot_exam 查体项的语境，路由由 few-shot 样例钉住。
3. **置信度 < 0.6 按 miss 处理**：患者答「没太注意」；miss 两次以上的主题进人工审阅队列（路由器迭代信号）。
4. **歧义处理示例**（few-shot 素材）：「晚上睡得怎么样」→ 含夜尿语境命中 `polydipsia_polyuria`（应答点里有「一晚上起来两三回」），纯睡眠语境 miss；「之前医生怎么说」→ `care_memory`。

## 三、judge I/O 合同（要点）

完整 schema 见 rubric JSON `judge_io_contract`。关键决定：**同批条款互不可见彼此判定**（防级联偏置：R16 判不成立不应影响 R17）；temperature 0；每条输出必须带 citation（layer + ref + quote），无引用的判定按 INSUFFICIENT_EVIDENCE 处理。

## 四、医学诚实声明（P0 阻挡项，不是脚注）

1. **本实例未经临床医生终审。** 所有阈值（高血压分级、HbA1c 强化治疗线）、药物剂量（恩格列净/缬沙坦）、ICD 编码（E11.x/I10.x 具体码）均为教学示意，标注【待核验】。上线前流程：执业医师逐条审订 → 核对 CDS《中国2型糖尿病防治指南（2020）》原文 → 修订 version 去掉 draft。
2. **费用是合成本院价目**，非真实价格；价位关系（TSH 贵于血常规）保留以支撑费用分条款。
3. 病例为**教学工程自构**：结构参照 AI Hospital 八字段，未逐字采用任何爱爱医原文（规避待核验的再分发风险）；临床情节合理性基于公开指南常识。
4. 患者姓名为虚构常见名，与真实人物无关。
