# 客户版全景图优先表达商业价值与创新性

门诊医疗 Agent 场景全景图面向客户展示，不出现内部验证平台名称。主要决策者是医院院领导、信息科和医务管理部门，临床科室是核心使用者。场景选择首先判断效率、质量、财务和患者服务四类商业价值，其次判断 Agent 相对规则自动化或单次模型调用的创新性，最后在内部规划中评估与现有工程能力的衔接；客户版使用定性的机会分组，不输出带有虚假精度的加权总分或内部产品适配分。

安全与合规不用于把高价值场景从机会地图中删除，但决定场景采用自动协作、责任人员确认还是先在仿真环境验证的落地形态。高商业价值不能被解释为允许未经验证的临床自治。

客户看完全景图后的目标动作，是选择两至三个场景进入联合调研与概念验证，而不是直接批准生产部署。客户沟通不宣称拥有更强的医疗模型，重点说明如何把 Agent 接入医院业务状态、工具、责任链和评测闭环；报告只展示场景机会、共用能力底座、证据与边界三层，不披露内部代码和组件架构。
