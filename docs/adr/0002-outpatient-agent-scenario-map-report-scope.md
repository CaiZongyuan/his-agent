# 按门诊诊疗流程与病历生命周期组织医疗 Agent 场景地图

医疗 Agent 场景报告不再只论证一个岗位绑定任务智能体，而是先发现并比较可从现有门诊能力拓展的应用场景。报告以门诊诊疗流程为业务主线，以病历生命周期为诊后利用主线，将候选场景分为当前可验证、未来 6-12 个月可拓展和长期研究三层。当前阶段先完成并审查全景图，不预先选择一两个场景深入分析；是否进入深入案例及选择哪些场景，在全景图稳定后另行决定。

这种结构保留 ClinMesh 当前实现作为工程证据，但不让现有实现限制场景发现，也不把接口存在、产品设想、论文实验或合成环境结果表述为真实医院落地。它取代 ADR-0001 的单场景范围，因为后者无法覆盖处方与医保审查、病历质控、教学评测、科研和受治理知识共享等沿门诊数据链自然出现的机会。

场景地图只覆盖一次门诊及其病历直接产生的后续用途，不扩展为全卫生健康行业目录。报告同时记录原子 AI 能力与智能体场景，但只把具有明确触发、责任人、条件化数据或工具调用、可验证结果及结束条件的有界工作流称为智能体场景；场景按业务闭环划分，原子能力作为其内部组件，而不把每项模型功能平铺为独立场景。
